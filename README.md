東京 Travel - 東京観光情報・予約サイト
📝 プロジェクト概要
本プロジェクトは、東京の観光スポット、グルメ、推し活（アニメ聖地など）の情報を検索・閲覧できる Web アプリケーションです。
ユーザーはエリアやカテゴリーからおすすめの場所を探すことができ、地図機能や画像の拡大機能、各サービスの予約ページも完備しています。

🛠 主な機能
ユーザー認証機能：新規会員登録、ログイン、ログアウト機能。

観光スポット検索機能：キーワード（場所名、エリア、カテゴリー）による検索。

動的カテゴリー表示：データベースからカテゴリーを動的に取得し、トップページに表示。

エリア別マップ：東京23区および23区以外の地図から、該当エリアの紹介ページへ遷移。

画像拡大機能（虫眼鏡）：地図画像にマウスを乗せると、その部分が拡大されるインタラクティブな機能。

情報登録機能：管理者用の画面から、新しいスポットやエリア情報を登録（画像アップロード対応）。

多言語対応：Google翻訳ウィジェットによる多言語切り替え。

💻 使用技術
バックエンド：PHP 8.x

データベース：MySQL (MariaDB)

フロントエンド：HTML5, CSS3, JavaScript (jQuery)

インフラ：InfinityFree (無料ホスティングサービス)

バージョン管理：Git / GitHub

🚀 ローカルでの実行方法
XAMPP などのローカルサーバー環境を準備します。

リポジトリをクローンし、htdocs フォルダ内に配置します。

phpMyAdmin を開き、tokyo_travel という名前のデータベースを作成します。

データベースにテーブルを作成（またはダンプファイルをインポート）します。

config.php のデータベース接続情報（ホスト名、ユーザー名、パスワード）を自身の環境に合わせて書き換えます。

ブラウザで http://localhost/Tokyo-Travel/index.html にアクセスします。
